# NSEE Desktop — Downloads

NSEE is a local-first, neuro-symbolic assistant: a compact reasoning core that plans, verifies and asks
before it changes anything on your computer. This repository only hosts the **desktop app downloads**.

## Download

Get the latest version from **[Releases](../../releases/latest)** → `nsee-desktop-vX.Y.Z.zip`.

## Install and run

1. Install **Python 3.10 or newer** from [python.org](https://www.python.org/downloads/) (tick *Add Python to PATH* on Windows).
2. Unzip the download anywhere, for example your Desktop.
3. Start NSEE:
   - **Windows:** double-click `launch_nsee.bat`
   - **macOS / Linux:** open a terminal in the folder and run `python3 launch_nsee.pyw`
4. NSEE opens in your browser at `http://127.0.0.1:8765`. It only listens on your own computer.

No other software, accounts or internet connection are needed. Your memory and files stay on your machine,
in the `data/` and `workspace/` folders next to the app.

## Try it without installing

Use **NSEE Web** from the NSEE website: guest chats need no account.
